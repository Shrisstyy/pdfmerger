# pdfmerger
A Python-based utility that merges multiple PDF files into a single document using PyPDF2, demonstrating file handling and automation.

Features:
1. Merge multiple PDF files into one  
2. User-friendly command line interface  
3. Fast and lightweight utility  
4. Automatically creates merged output file  

Requirements:
Before running this project, make sure you have:

1. Python 3.8+  
2. PyPDF2 library installed  

Example:
How many pdfs do you want to merge?
3

Enter the name of the pdf 1:
file1.pdf

Enter the name of the pdf 2:
file2.pdf

Enter the name of the pdf 3:
file3.pdf

Output:
merged-pdf.pdf
